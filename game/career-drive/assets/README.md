# Dialogue character assets

`damian-character-hazel.png` is the static fallback. `damian-expression-sheet.png` is a registered 3-column by 2-row sheet; each tile is a full 3:4 portrait. `portrait.js` crops its frames at runtime.

Frames, left to right:

1. Neutral, eyes open, mouth closed.
2. Closed-eye blink.
3. Neutral talking mouth.
4. Warm smile, mouth closed.
5. Warm smile, talking mouth.
6. Thoughtful resting expression.

The assets were created with the built-in Imagegen tool, using the existing cartoon character as the identity and style reference. The final editing brief changes only the iris palette: muted olive/sage green, a warm hazel-brown centre and a subtle desaturated blue-grey outer edge. Preserve the same pose, framing, lighting and facial alignment across all six frames when replacing this sheet. The eye-reference photographs are not included in this repository.
